# Movie Recommendation System

## Project Overview

This project is a simple movie recommendation system developed using
Python. It recommends movies that are similar to a movie selected by
the user.

The system uses the genres of movies to identify similar movies.

## Objective

The objective of this project is to build a basic recommendation system
that can suggest movies based on the similarity between their genres.

## How It Works

The system follows these steps:

1. Loads the movie dataset using Pandas.
2. Processes the movie genre information.
3. Converts movie genres into numerical features using TF-IDF.
4. Calculates the similarity between movies using cosine similarity.
5. Takes a movie title as input from the user.
6. Displays five recommended movies.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
