# Tic-Tac-Toe AI

## Project Overview

This project implements a Tic-Tac-Toe game in Python where a human
player competes against an AI opponent.

The AI uses the Minimax algorithm to analyze possible moves and select
the best available move.

## Objective

The objective of this project is to create an AI agent that can play
Tic-Tac-Toe against a human player using a game-search algorithm.

## Features

- Human vs AI gameplay
- Minimax-based AI
- Automatic AI move selection
- Win detection
- Draw detection
- Input validation
- Command-line interface

## Algorithm

The project uses the **Minimax algorithm**.

Minimax evaluates possible future game states and chooses a move that
maximizes the AI's outcome while minimizing the opponent's advantage.

The human player uses `X`, while the AI uses `O`.

## Technologies Used

- Python
- Minimax Algorithm
- Basic Game Theory
- Command-Line Interface

## Requirements

Python 3.x is required.

No external Python packages are required because the program uses Python
standard-library modules.
