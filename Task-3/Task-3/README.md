# Rule-Based Chatbot

## Project Overview

This project implements a simple rule-based chatbot using Python.

The chatbot responds to user messages using predefined rules and
pattern matching techniques. It provides suitable responses for common
questions and conversational inputs.

## Objective

The objective of this project is to build a chatbot that can identify
different types of user queries and provide appropriate responses using
predefined rules.

## Features

- Rule-based responses
- Pattern matching
- Greeting responses
- Questions about Python and AI
- Chatbot-related questions
- Help command
- Thank-you responses
- Good morning, afternoon, evening and night responses
- Exit command
- Unknown-input handling
- Graphical user interface

## Technologies Used

- Python
- Regular Expressions
- If-Else Statements
- Tkinter

## How It Works

The chatbot converts the user's input into lowercase text and checks it
against predefined rules.

Based on the detected words or phrases, the chatbot returns a suitable
response.
